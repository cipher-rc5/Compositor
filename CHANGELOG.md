# Changelog

All notable changes to Compositor are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow the app's marketing version
(`MARKETING_VERSION`), tagged `v<version>`.

## [Unreleased]

### Added

- Camera Raw Filter, in a workspace docked beside the canvas: Light, Color, Effects, Curve, Color Mixer,
  Color Grading, Detail, Optics, Geometry and Calibration, with a live histogram and auto white balance.
- Gaussian Blur, Motion Blur and Add Noise adjustment layers (project format version 9).
- Image › Trim…, trimming transparent pixels or the top-left or bottom-right pixel color from chosen edges.
- Inner Glow layer effect.
- Crash recovery: unsaved projects are snapshotted to Application Support every 30 seconds and when the app
  goes to the background, and a Restore / Discard sheet offers them back after a crash.
- Unified logging (subsystem `com.wonderassembly.compositor`) for recovery, effects rendering, dropped
  background results, window plumbing and keyboard-shortcut settings.
- Accessibility labels, values and adjustable actions for the color-grade wheels, curve editor, Hue/Saturation
  spectrum handles, swatches and the aspect-ratio link.
- Hosted CI: a GitHub Actions workflow runs `scripts/ci.sh` on every push to `main` and every pull request,
  with Xcode 26.6 and Xcode 27.0, and a weekly Sanitizers workflow runs the unit tests under Address and
  Undefined Behavior Sanitizers (`just test-sanitized` locally). The **Compositor** scheme is shared, so
  builds no longer rely on an autogenerated one.
- `just ci` and `just hooks`: the local CI gate (clean, warning-free build plus unit tests) and a pre-push
  hook that runs it.
- Releases carry a SHA-256 checksum (`Compositor.dmg.sha256`) and an SPDX bill of materials
  (`Compositor.spdx.json`) beside the DMG.
- Dependabot updates for Sparkle and the GitHub Actions the workflows use.
- `SECURITY.md`, `CONTRIBUTING.md`, this changelog, and an `.editorconfig`.

### Changed

- Heavy work no longer runs on the main thread: brush coverage on the GPU, layer-effect rendering, cache
  misses while drawing, Spot Healing, Distort's Apply, the composites behind Merge, Magic Wand, Select Subject
  and Copy Merged, Copy's PNG encoding, the Blur filter's padding and Smudge/Liquify's dabs (now in C).
- Content-Aware Fill works on the selection plus a sampling margin instead of the whole layer.
- Undo history tracks its memory use incrementally instead of rescanning every entry on each edit.
- Layer effects allocate GPU buffers only for the effects that are on.
- The tab strip no longer polls the pasteboard; it reacts to drags as they arrive.
- The Layers panel handles tool keys (including `[ ] { }`) through the same dispatcher as the canvas.
- One View › Snap toggle replaces the two that controlled different things.
- Undo, layer edits and project operations are gated by a single list of modal states.
- One effects-panel session (adding an effect, dragging its sliders, picking colors) is one undo step, and
  Cancel leaves nothing to undo.
- Undo history counts painted layers by the tiles they share, so large photos keep many more undo steps.
- Saving reuses the encoded PNG of every layer that hasn't changed, and the manifest is written compactly.
- Opening Filters, Hue/Saturation and Levels on a large layer, Blur and Clone Stamp's first click, applying
  a floating selection or distortion, Load Selection, and Camera Raw's auto white balance no longer block the
  window while they read the image.
- Dragging a gradient repaints only what the canvas shows; the full layer is painted on release.
- The Effects panel closes, keeping its edits, when you switch tabs.
- Import Images waits for the same conditions as Open and Save.
- Apply and Cancel can't be remapped to a bare letter, which would fire while typing.
- The ⌥⌘H shortcut is listed as Hide Others, matching the menu.
- `scripts/ci.sh` reports the app's line coverage; `scripts/test-sanitized.sh` fails if the run is cut short.
- The project builds in the Swift 6 language mode, with a `justfile` for common tasks; test targets moved
  under `Tests/`.
- `scripts/release.sh` runs the CI gate before archiving and records the commit it built.
- `scripts/publish.sh` publishes to the `origin` repository (or `REPO`), and refuses unless that repository
  serves the feed the app reads (`SUFeedURL`), the Sparkle key matches the app's, it runs on a clean `main`
  that matches `origin/main`, the DMG was built from that commit, and CI passed on it.
- Grain's size setting behaves more predictably.
- `docs/project-format.md` covers versions 7–9: adjustment layers, guides, blur and noise adjustments, Inner
  Glow, shape layers, mask placement and linking, and the layer name limit.

### Fixed

- Layer effects were dropped by edits that replace a layer's pixels (filters, Levels,
  Hue/Saturation, selection edits, dropping a moved selection), by Canvas Size, Image Size, Crop and Trim,
  and when copying layers between projects.
- Undo could lose the step just made when one edit to a very large image exceeded the history's memory limit
  on its own.
- The project loader rejected some projects the app itself now writes.
- The Camera Raw Balance slider, and the test fixtures that hid its error.
- Cut cleared the selection's pixels even when the copy failed.
- Select Subject could reuse a mask from a different, freed image.
- After a Gaussian Blur, the layer mask drifted away from the pixels.
- Reopening Hue/Saturation right after Cancel left the preview stuck.
- Blur and Clone Stamp on a canvas too large for their buffers did nothing, without a message.
- A failed layer-effects preview made the effects vanish from the canvas; it now keeps the last result and
  retries.
- A RAW file that fails to develop now says so and disables Import.
- Magic Wand and Object Selection trapped on a non-finite click point.
- A file dropped while an edit was in progress could wait forever; it now times out with a message.
- A save that couldn't replace the existing project (for example in a read-only folder) emptied the old
  package before failing; saves now write a complete copy beside it and swap it in.
- Color Noise Reduction and Sharpen read uninitialised memory around transparent pixels, giving different or
  black results; holes no longer darken, desaturate or sharpen their neighbours.
- Camera Raw steps that run out of memory are reported instead of committing a partial result.
- Hue/Saturation opened while a gradient was pending did nothing.
- Camera Raw Geometry Scale at −100 collapsed the picture; it now halves it.
- Colorize with a negative hue now wraps around the wheel.
- Levels reports histogram and preview errors instead of an empty histogram.
- Photoshop Levels gamma and Hue/Saturation (`hue2`) adjustments are decoded as the format specifies.
- Duplicate, Paste, Layer via Copy, shapes and text refuse to push the document past its 100-megapixel
  budget, which made it unsaveable.
- A floating selection whose pixels couldn't be lifted duplicated them instead of moving them.
- Merge failures are reported instead of a beep.
- Smudge and Liquify no longer share their working pixels with the image the canvas draws from another thread.
- Blur no longer fades the canvas edges.
- A Line click without a drag no longer makes a layer; Smudge/Liquify ignore non-finite pointer positions.
- Move Layer Up/Down from the menu now joins and releases clipping groups as dragging does.
- Effects too large to render (a shadow thousands of pixels away) make export fail with a message naming the
  layer, instead of disappearing.
- After a crash, restored projects are snapshotted again straight away, so a second crash can't lose them.

### Security

- PSD import keeps to the limits a saved project must meet: masks have their own 100-megapixel budget
  (counting masks already in the document), folders nest at most 64 deep, names are trimmed to 16 KiB and
  origins clamped, and any file cut short reports as truncated.
- Project loading validates layer effects and shapes, and reports symlinked, missing or non-regular assets
  accurately.
- A PSD whose layer records each claim a block larger than the record is refused as truncated, instead of
  being copied once per record until memory runs out.
- A project whose manifest would exceed 4 MiB is refused when validated, so a document that validates can
  always be saved.
- A developed RAW image is checked against the size limits again before it is inserted.
- A PSD whose block length is near `Int.max` (8B64 blocks) is reported as truncated instead of trapping the
  app on an arithmetic overflow.

## [1.2.2] - 2026-09-21

### Added

- Photoshop's remaining blend modes, grouped as Photoshop groups them.
- Invert, Black & White and Color Balance adjustments and adjustment layers.

## [1.2.1] - 2026-09-21

### Added

- Opening camera RAW files, through a develop step for exposure, white balance and tone.
- Panning with the middle mouse button.

### Changed

- Auto Select picks the foreground layer under the pointer, and tool settings persist between launches.
- The app icon follows Apple's icon grid.
